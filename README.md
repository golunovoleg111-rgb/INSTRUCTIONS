# Beltanee — рабочие инструкции

Простой статический справочник для команды: FBS SCANER, конвертер сборочных заданий, FBS Хранение и планирование перемещений.

Раздел конвертера учитывает выбор единого PDF или двух отдельных файлов для смешанного задания Beltanee и Beltane Man.

Сайт: https://golunovoleg111-rgb.github.io/INSTRUCTIONS/

## Редактирование

- `index.html` — тексты, шаги и ссылки на сервисы.
- `styles.css` — оформление, адаптация к телефону и печати.
- `app.js` — выделение текущего раздела в меню.
- `assets/` — скриншоты пользователя.

Сборка и зависимости не требуются. GitHub Pages публикует корень ветки `main`. Для локального просмотра достаточно открыть `index.html` в браузере.

Логин и пароль сканера не публикуются. На сайте указано, что их нужно получить у ответственного.

Порядок планирования дополнен по рабочему циклу скрипта FBS Planner v5.2 из предыдущей задачи: входящие папки, предварительный расчёт, ручное дополнение, фиксация, резерв и PDF. Предыдущая задача о v5.2.1 не подтверждает установку новой версии в рабочей таблице. Перед изменением процедуры сверяйте названия команд с используемой версией скрипта.
